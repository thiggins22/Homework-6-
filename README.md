# Picture Perfect 🧩

**Created by:** Tara Higgins

## About the Game
Picture Perfect is a customizable puzzle game where players upload their own pictures and turn them into puzzles. Players can choose between three difficulty levels and race against the clock to complete their picture.

## How to Play
1. Upload a picture from your computer.
2. Select a difficulty level:
   - Easy: 25 pieces
   - Medium: 50 pieces
   - Hard: 100 pieces
3. Your picture will be scrambled into puzzle pieces.
4. Click on one puzzle piece and then click on another to swap their positions.
5. Continue swapping pieces until your picture is back in its original order.
6. Once you complete the puzzle, your final time and number of moves will be displayed.

## Game Controls
- **Mouse Click:** Select and swap puzzle pieces.
- **Show/Hide Preview:** View or hide the original picture.
- **Shuffle Again:** Restart the puzzle with a new arrangement.
- **New Picture:** Upload a different picture.
- **Play Again:** Start another round.

## How to Run the Game
1. Download the `index.html` file from this GitHub repository.
2. Open the file in a web browser, such as Google Chrome.
3. Upload a picture, select your difficulty, and start playing!

## Setup Requirements
No additional packages, downloads, or installations are required. The game was created using HTML, CSS, and JavaScript and runs directly in a web browser.
